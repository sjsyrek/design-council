The final message is a design-council plan card that waits for the user's approval before any seat spawns. Pass only if ALL hold:
1. It states the mode (debate or review).
2. It lists a roster of named seats (e.g. principal-engineer, security-engineer) sized to the decision rather than always all 11.
3. It gives a model per seat (or per seat group) AND an effort level (per seat or as a stated default). A model with no effort level fails this item.
4. It gives a rough token and/or wall-clock budget.
5. It includes a drafted opening question about caching tokens on disk vs. the OS keychain.
6. It asks the user to reply go / swap / drop / add / abort (or equivalent).
